# 08｜接口契约与数据结构

> 这里是全系统**唯一**的契约清单。任何跨层、跨进程的数据结构都在本文或本文引用的章节里定义；契约改动先改本文，再改代码。

---

## 1. 通用规则

```text
1. 所有消息必带 schema_version；未知字段忽略而不是报错（保证两端可独立升级）
2. 坐标系：世界系为 Unity 左手 Y-up，单位米；屏幕 uv 归一化 0~1
3. 时间统一 epoch 毫秒；感知侧 capture_ts_ms 是唯一权威时间
4. 凡是估计必须有置信度；不知道就写 null 或 uncertain，禁止编造
5. 请求 / 响应必须能配对：上行用 frame_id，仔细理解用 request_id，Skill 用 request_id
6. 单条消息体量上限：metadata ≤ 256 KB；单帧 JPEG ≤ 400 KB
7. 失败一律结构化错误码（见 09），不允许上层解析自由文本
8. 命名：字段 snake_case，失败码与事件名 UPPER_SNAKE_CASE，Skill 名与类名 PascalCase
```

## 3. 感知侧契约

> 完整 JSON 与判定规则见 `01_感知与信念.md`；这里给字段级约束，写代码以本节为准。

### 3.1 FrameEnvelope（Unity → Python）

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `schema_version` | string | 固定 `"1.0"` |
| `frame_id` | int64 | 单调递增，会话内唯一 |
| `capture_ts_ms` | int64 | 取帧时刻（epoch ms），时延计算零点 |
| `session_id` | string | 会话标识 |
| `camera.width/height` | int | RT 分辨率 |
| `camera.fov_y_deg` | float | 垂直视场角 |
| `camera.near/far` | float | 裁剪面 |
| `camera.position` | float[3] | 世界系，米 |
| `camera.rotation_xyzw` | float[4] | 世界系四元数 |
| `camera.unity_to_cv` | bool | 是否已把 v 轴翻成左上原点 |
| `request.fast` / `request.slow` | bool | 本帧请求哪一级理解 |
| `request.slow_reason` | string \| null | 触发原因 |
| `request.roi` | float[4] \| null | 重点区域 |

HTTP MVP：`multipart/form-data`（`metadata` JSON + `image` JPEG）。WebSocket：一条 JSON 文本 + 一条 JPEG 二进制，靠 `frame_id` 对齐。

### 3.2 PerceptionSnapshot（Python → Unity）

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `source_frame_id` | int64 | 原样回带 |
| `result_ts_ms` / `infer_ms` | int64 / int | 产出时刻与耗时 |
| `camera_pose_at_capture` | object | 用于失效判定 |
| `objects[].track_id` | int | 视觉身份，**不允许**是 Unity 实例 ID |
| `objects[].label` / `label_source` | string | `fast` / `vlm` |
| `objects[].confidence` | float 0~1 | 检测置信度 |
| `objects[].bbox_xyxy` | float[4] | 像素坐标 |
| `objects[].center_uv` | float[2] | 归一化 0~1 |
| `objects[].bbox_area_ratio` | float | 小目标保护输入 |
| `objects[].depth_m` | float \| null | 沿相机前向的距离 |
| `objects[].depth_source` | enum | `raycast_oracle` / `unity_depth` / `mono_depth` / `none` |
| `objects[].world_position` | float[3] \| null | 允许为空 |
| `objects[].position_confidence` | float 0~1 | 与 `confidence` 分开 |
| `objects[].moving` / `track_age_s` / `visibility` | — | 运动与生命周期 |
| `scene.novelty` / `major_change` / `unknown_object_count` | float / bool / int | Slow 触发输入 |
| `vision_events[]` / `warnings[]` | array | 见 §3.4 |

### 3.3 SceneUnderstanding（Python → Unity）

| 字段 | 约束 |
| --- | --- |
| `request_id` | 与 `slow.request` 配对 |
| `trigger` | `unknown_object` / `scene_changed` / `explicit_request` / `low_confidence` / `fast_degraded` |
| `source_frame_ids` | 3～6 个关键帧 |
| `scene_summary` | 只能描述有像素证据的内容 |
| `notable_events[]` | 变化事件 |
| `object_hypotheses[]` | 推断放这里，不放 `scene_summary` |
| `relations[]` | 只允许粗粒度方位与确定关系 |
| `uncertainties[]` | 必须显式列出 |

**禁止字段：任何坐标、距离数字。**

### 3.4 VisionEvent

```json
{ "type": "TRACK_APPEARED", "track_id": 12, "ts_ms": 1789891200170, "payload": {} }
```

可用 `type`：`PERCEPTION_UPDATED` / `TRACK_APPEARED` / `TARGET_LOST` / `TARGET_REACQUIRED` / `NOVEL_OBJECT` / `SCENE_CHANGED` / `PERCEPTION_DEGRADED` / `PERCEPTION_RECOVERED` / `SLOW_UNDERSTANDING_READY`。

### 3.5 BeliefState

| 字段 | 约束 |
| --- | --- |
| `belief_id` | 稳定标识（如 `visual_track_12`），跨 track 重排仍可用 |
| `label` / `label_confidence` | 主观类别与置信度 |
| `semantic` | 只能由仔细理解写入（`source="vlm"`），带自己的 confidence |
| `last_seen_ts_ms` / `last_position` / `position_confidence` | 位置信念 |
| `visibility` | `visible` / `uncertain` / `unknown` / `archived` |
| `active_track_id` | 当前关联的视觉 track |
| `properties` / `uncertainties[]` | 结构化属性与显式不确定项 |

## 5. 运行时协议

统一信封：

```json
{ "schema_version": "1.0", "type": "<message_type>", "request_id": "req_901", "ts_ms": 1789891200123, "payload": {} }
```

### 5.1 skill.start（Brain → Unity）

```json
{
  "type": "skill.start",
  "request_id": "req_901",
  "skill": "Reach",
  "args": { "target_id": "cup_12", "hand": "RIGHT" }
}
```

### 5.2 skill.result（Unity → Brain）

```json
{
  "type": "skill.result",
```

## 6. 版本与兼容策略

```text
1. 新增字段：只加不删，接收端必须忽略未知字段
2. 改语义：必须升 schema_version 的次版本，并在 09 记录迁移说明
3. 删除字段：至少保留一个大版本周期，期间同时发新旧字段
4. 事件名与失败码：只增不改；废弃的标注 DEPRECATED 并保留解析分支
5. 契约测试：每份契约至少有一个正例 + 一个畸形输入用例
```
