# 09｜术语表与失败码总表

---

## 1. 术语

| 术语 | 含义 |
| --- | --- |
| Observation | 单个对象的一次视觉观测（object / confidence / timestamp / uncertainty / source 五元组） |
| 快理解 / Fast Vision | 高频、几何与身份导向的视觉：检测、跟踪、深度→三维、运动 |
| 仔细理解 / Slow Vision | 低频、事件触发的语义理解：VLM 场景描述、未知物解释 |
| PerceptionSnapshot | 一帧的视觉结论集合，**几何权威** |
| SceneUnderstanding | 一次仔细理解的结论，**语义权威**，不碰几何 |
| Belief / BeliefState | 角色的主观世界模型，允许错、会衰减 |
| WorldTruth / WorldTruthState | Unity 的真实状态，只用于验证与调试 |
| stale | 结果因帧龄或相机位姿变化而失效 |
| track churn | 跟踪稳定性指标：新 track 生成速率 / 平均存活数 |
| 重投影误差 | 估计的三维点投回屏幕后与检测中心的偏差，坐标链正确性的核心指标 |
| AgentState | 运行时权威状态（Identity / Needs / Goal / Belief / Body / Memory / Events） |
| Fast Policy | 确定性快决策层（JEV 风格），输出 Typed Decision |
| Typed Decision | 类型化决策，如 `{ "decision": "WALK_FIRST", "confidence": 0.93 }` |
| Skill | 可启动、可 Tick、可取消、可验证、可失败恢复的行为单元 |
| SkillContract | Skill 的静态定义（输入、资源、超时、前置条件、Verifier、失败码） |
| BodyIntent | Brain/Skill → Motor 的唯一接口（意图，不是关节角） |
| BodyState | Motor → Brain/Skill 的身体语义状态 + 本体感觉 |
| Effector | RigGraph 的控制点（`RigEffector`），运行时被程序驱动的对象 |
| Control Rig | RigGraph 的节点图资产（`RigGraphAsset` / `ModularRigGraphAsset`） |
| Verifier | 用可验证量（位置、接触、持续帧数）判定 Skill 是否真正成功 |
| Procedural Memory | 从遥测与历史中归纳的"怎样做更容易成功" |
| Session | 一次感知服务生命周期；会话切换会重置 track 关联 |

## 2. 失败码规范

失败码必须：

```text
1. 机器可解析（上层直接 switch，不做文本匹配）
2. 前缀表达来源层
3. 只增不改；废弃码保留解析分支并标 DEPRECATED
```

### 2.1 前缀

| 前缀 | 来源 | 说明 |
| --- | --- | --- |
| `PERCEPTION_` | 感知层 | 模型、推理、快理解 |
| `SLOW_` | 仔细理解 | VLM 后端相关 |
| `TRANSPORT_` | 传输层 | 连接、体积、回读 |
| `TARGET_` | 目标状态 | 目标丢失、移动、歧义 |
| `PATH_` | 路径规划 | 无路、被堵 |
| `IK_` | 运动求解 | 关节极限、求解失败 |
| `MOTOR_` | 运动控制 | 未收敛、不稳定 |
| `GRASP_` | 抓取 | 无接触、滑落 |
| `PHYSICS_` | 物理 | 碰撞异常、穿模 |
| `TIMEOUT_` | 超时 | 未在预算内完成 |
| `CANCELLED_` | 取消 | 人类、上层、系统取消 |

### 2.2 具体失败码

| 失败码 | 含义 | 典型恢复 |
| --- | --- | --- |
| `PERCEPTION_MODEL_UNAVAILABLE` | 模型未加载 / 加载失败 | 保留上一次快照并标 `stale` |
| `PERCEPTION_LOW_CONFIDENCE` | 检测整体低置信度 | 压低 `position_confidence`，触发 Slow |
| `PERCEPTION_DEGRADED` | 连续多帧超时 | 降采集频率，面板转黄 |
| `PERCEPTION_INFER_FAILED` | 单帧推理异常 | 丢帧不重试 |
| `SLOW_TIMEOUT` | 仔细理解超时 | 放弃本次，记熔断计数 |
| `SLOW_BAD_OUTPUT` | 输出 JSON / schema 校验失败 | 降级为 fast-only |
| `SLOW_BACKEND_ERROR` | 后端网络或服务错误 | 重试一次后放弃 |
| `TRANSPORT_READBACK_ERROR` | GPU 回读失败 | 丢帧计数 |
| `TRANSPORT_OVERSIZE` | 消息超体积上限 | 丢弃并计数 |
| `TRANSPORT_DISCONNECTED` | 连接断开 | 退避重连，进入离线模式 |
| `TARGET_LOST` | 目标连续未出现 | `SEARCH` / `SCAN_AREA` |
| `TARGET_MOVED` | 目标位移超出 gate | 重新观察、重建 plan |
| `TARGET_AMBIGUOUS` | 多个候选无法区分 | `Inspect` / `AskHuman` |
| `PATH_NO_ROUTE` | 无可行路径 | `REPLAN_PATH` / `ASK_HUMAN` |
| `PATH_BLOCKED` | 路径被临时阻挡 | `REPLAN_PATH` / `WAIT` |
| `IK_LIMIT` | 关节达到极限 | 脊柱补偿 / 迈步 / 重新观察 |
| `IK_UNREACHABLE` | 位置不可达 | `MOVE_CLOSER` |
| `MOTOR_NOT_SETTLED` | 目标到位但未稳定 | 延长 Settle 或降速 |
| `MOTOR_UNSTABLE` | 运动过程失衡 | `STABILIZE` |
| `GRASP_NO_CONTACT` | 未建立接触 | 重新对齐抓取姿态 |
| `GRASP_OBJECT_SLIPPED` | 抓后滑落 | 重抓；失败超阈值则报告 |
| `PHYSICS_COLLISION_BLOCKED` | 碰撞阻断动作 | 调整接近方向 |
| `BALANCE_UNSTABLE` | 支撑多边形外 | 修正步 / 降速 |
| `TIMEOUT_GAZE_NOT_CENTERED` | 注视未在时限内居中 | 重试 / 换策略 |
| `TIMEOUT_MOTOR_NOT_SETTLED` | 运动未在时限内稳定 | 降速重试 |
| `TIMEOUT_PATH_BLOCKED` | 路径超时未通 | 重新规划 |
| `CANCELLED_BY_HUMAN` | 人类 STOP | 立即停止，释放资源锁 |
| `CANCELLED_BY_SYSTEM` | 上层重规划 / 优先级抢占 | 释放资源锁，回到 Idle |

### 2.3 使用示例

```json
{
  "skill": "Reach",
  "success": false,
  "code": "IK_LIMIT",
  "message": "elbow reached 178deg limit at t=1.02s",
  "details": { "joint": "RightLowerArm", "angle_deg": 178.0 }
}
```

## 3. 资源名与事件名

```text
资源（Resource Lock）
  GAZE / ROOT / LEFT_ARM / RIGHT_ARM / LEFT_HAND / RIGHT_HAND / SPINE / LEGS / FULL_BODY

事件（Event）
  PerceptionUpdated / TrackAppeared / TargetLost / TargetReacquired / NovelObject
  SceneChanged / PerceptionDegraded / PerceptionRecovered / SlowUnderstandingReady
  SkillSucceeded / SkillFailed / SkillCancelled
  HumanCommand / NeedThresholdCrossed / GoalCompleted / GoalFailed
  Timer / MemoryConsolidated
```
